# Browser Forensic Analyzer - Frontend

Initial PySide6 frontend for the browser forensic application.

## Run

From this directory:

```text
python main.py
```

## Current UI

- Source / drive / disk-image selection
- Browser selection
- Analyze button
- Findings panel
- Analysis Log panel
- Status bar

The browser list and source list are currently placeholder data.
The next step is to connect the existing browser detector to the UI.
